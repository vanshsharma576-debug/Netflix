# 🎬 Netflix Content Analysis

An end-to-end **Exploratory Data Analysis (EDA)** project analyzing Netflix's content library to uncover trends in movies, TV shows, countries, creators, and content releases.

## 🔍 What I Analyzed

- 🎥 Movies vs. TV Shows distribution
- 🌎 Country-wise content availability
- 📅 Content release and addition trends
- 🎭 Top directors and actors
- 🗓️ Monthly content addition patterns
- 📊 Country × month content trends using heatmaps

## 💡 Key Insights

- Netflix's catalog contains **8,807 titles**, with Movies significantly outnumbering TV Shows.
- The **United States** has the largest content volume, followed by **India** and the **United Kingdom**.
- Movie releases showed a strong upward trend, peaking around **2017–2018**.
- Movies and TV Shows showed distinct top talent pools, with little overlap among leading directors and actors.
